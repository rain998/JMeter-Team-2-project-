# JMeter-Team-2-project-
This is the repo for our project.
###As a new user I can register an account to start tracking my todo tasks- 
  Users typically only register one time therefore 10% of the traffic on the application would be registration. 
###As a new user I can log in and out to securely access my todo items- 
  User login to access their tasks and subtask not all users are editing their task and subtasks therefore they only account for 20% of the load in the application. 
###As a user I can create and edit todo items to keep track of my work- 
  not every person will create a subtask list most will only just do a todo list and that will be sufficient for them therefore we believe it will account for 40% of the traffic.
###As a user I can create and edit subtask items to better organize my primary tasks- 
  30% of the traffic will be directed towards our users that are building sub tasks on their todo list, its less frequent because we believe most people will not need to organize beyond a regular todo list.
