# JMeter-Team-2-project-
This is the repo for our project.
## As a new user I can register an account to start tracking my todo tasks- 10%
  Users typically only register one time; therefore, 10% of the traffic on the application would be registration. 
## As a new user I can log in and out to securely access my todo items- 20%
  Users login to access their tasks and subtasks. Not all users are editing their tasks and subtasks; therefore, they only account for 20% of the load in the application.
## As a user I can create and edit todo items to keep track of my work- 40%
  The majority of the traffic for this application would be for creating and editing tasks; therefore we believe it will account for 40%.
## As a user I can create and edit subtask items to better organize my primary tasks- 30% 
  Not every person will create a subtask list. Most will only create a main todo list which would be sufficient for them; therefore, we believe it will account for 30% of the traffic.
